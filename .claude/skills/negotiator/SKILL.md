# negotiator

## Precedent / mapping
Offer and compensation strategy — the bottom-of-funnel stage most job-search tools skip entirely.

## Inputs
The offer details, `profile/04-job-evaluation.md` (comp floor), market benchmarks (web
search / any salary data the user brings).

## Output
- Benchmark range for the role/level/location.
- Strategy options with trade-offs (what each prioritizes).
- Draftable scripts for the conversation — the user delivers them.

Frame as information for the user's own decision, not a directive. Not financial/legal advice.
