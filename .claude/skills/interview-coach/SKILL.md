# interview-coach

## The differentiated idea — hiring-side inversion
Install and read Lenny's **hiring-side** skills and reason from the interviewer's seat:
- `evaluating-candidates` → what a hiring manager literally scores → invert to prepare
- `conducting-interviews` → the interviewer's playbook → anticipate structure and probes
- (`writing-job-descriptions` via `company-research`) → what the JD is really anxious about

The distinctive move here: feed the coach the *hiring-side* skills — how interviewers evaluate
candidates, structure loops, and write the JD — so it prepares you from the interviewer's seat.
You walk in already holding the hiring manager's own playbook.

## Inputs
`profile/07-interview-prep.md` (STAR bank), `company-research` output, the JD.

## Output
- Likely questions for THIS role and level (Staff/Group probes: vision, influence without
  authority, systems thinking, trade-offs, an owned failure, AI depth).
- For each: which of the user's *real* STAR stories answers it, and how to frame it.
- Gaps: probes with no strong story yet → flag for more prep (don't fabricate one).
