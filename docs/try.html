To get one: open console.anthropic.com/settings/keys, sign in, click Create Key, then copy the sk-ant-… string it shows you once.
No Anthropic key?
One is required today. This page is a single file with no server behind it, so your browser has to talk to Anthropic itself, using your key. Creating one takes about a minute and needs a payment method. A tailoring costs a few cents, billed to you by Anthropic.

A Claude Pro or Max subscription is not an API key. They are separate things and a subscription does not carry over to this page. If you have one, you are better off skipping this page entirely: your subscription already pays for the full agent, which does far more than this single step.

Or skip the key entirely. This page is one instruction to Claude with your CV and the posting attached. You can run that instruction yourself, in Claude, on a free account, with nothing to install and nothing to pay. Fill in your CV and the posting above, then:

What that button does. Everything above was built from the CV you pasted in, and when this tab closes it all goes with it. The full agent opens by interviewing you about your career, which takes real time and asks you for things you already typed here.

So: it reads your CV once more and hands you a small file, on your machine, that a fresh install turns into a working profile. You skip the part you already did. Then one command sets it up and the agent starts from your history rather than from nothing.

Read it before you trust it. The file is plain text and it is yours alone. Nothing is uploaded, because there is no server here. But it is a model reading your CV, so a date can land wrong or a number can sit under the wrong job, and those become the facts every later document is checked against. The agent will keep telling you it is unverified until you have read it through.
